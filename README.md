# مقام

منصة عربية تفاعلية لتعلّم المقامات العربية وعزفها في المتصفح.

- **المقامات الثمانية**: راست، بيات، سيكاه، حجاز، صبا، نهاوند، عجم، كرد. لكل مقام صفحة فيها أجناسه وسيره وجملة مسموعة.
- **سلّم الحجرات**: كل مقام مرسوم كصفّ من الطابوق المزجّج (على طريقة بوابة عشتار)، وعرض كل حجرة يساوي المسافة الحقيقية بالسنت. ربع الصوت حجرة أضيق فعلاً.
- **عود في المتصفح**: صوت وتر مقطوف مولّد بخوارزمية Karplus–Strong، مضبوط بدقة أقل من ٤ سنت (هناك اختبار لذلك).
- **الاستوديو**: ١٥ نغمة على لوحة المفاتيح أو اللمس، تسجيل وإعادة وحفظ ونشر.
- **درّب أذنك**: عشر جولات، كل الأسئلة من القرار نفسه، والنتائج تُحفظ لكل مقام.
- **المعرض**: مقطوعات الزوار مع الإعجابات والمشاركة.
- **المسار**: تسعة دروس من العجم إلى السيكاه، كل درس ينتهي باختبار (أسئلة اختيار، «اضغط على الحجرة»، و«أي مقام تسمع؟»). التقدّم يُحفظ للزائر في المتصفح ويُرفع إلى حسابه عند الدخول.
- **المُدوزِن**: يسمع الميكروفون (خوارزمية YIN)، يعرض النغمة بالاسم العربي وانحرافها بالسنت، يضعها على سلّم المقام، ويخمّن المقام من جملة مغنّاة بأي طبقة.
- **خريطة المقامات**: شبكة القرابة بين المقامات بحسب النغمات المشتركة، مع الاستماع إلى الانتقال.
- **المجتمع**: تعليقات، «أعد عزفها» (نسخة من مقطوعة غيرك ترتبط بالأصل)، صفحات عامة للأعضاء، لوحة صدارة أسبوعية، وتنزيل أي مقطوعة كملف WAV.
- **الإنجازات**: تسعة إنجازات وسلسلة أيام متتالية.
- **الإشراف**: بلاغات على المقطوعات والتعليقات، إخفاء وإظهار، وإحصاءات الموقع.
- **تطبيق قابل للتثبيت (PWA)**: يعمل هيكله دون اتصال.
- **حسابات**: تسجيل ودخول بجلسات آمنة (كوكي httpOnly، كلمات مرور bcrypt، تحديد معدّل المحاولات).

## المشرفون

```bash
npm run make-admin -w server -- someone@example.com
```

أو اضبط `ADMIN_EMAILS=a@x.com,b@y.com` فيصير أصحاب هذه العناوين مشرفين عند التسجيل أو الدخول.

## التشغيل

```bash
npm install
npm run build
npm start          # http://localhost:4300
```

للتطوير (خادم + Vite مع إعادة تحميل فورية):

```bash
npm run dev        # الواجهة على http://localhost:5173
```

الاختبارات:

```bash
npm test
```

بـ Docker:

```bash
docker build -t maqam .
docker run -p 4300:4300 -v maqam-data:/data maqam
```

## البنية

```
server/   Express + SQLite (better-sqlite3)
  src/app.js                 تجميع الخادم
  src/routes/auth.js         الحسابات والجلسات
  src/routes/compositions.js المقطوعات، الإعجابات، التعليقات، البلاغات، الصفحات العامة
  src/routes/learn.js        التدريب، الدروس، الإنجازات، لوحة الصدارة
  src/routes/admin.js        الإشراف
  src/db.js                  المخطط والترحيلات
  src/seed.js    مقطوعات أولى لفرقة «مقام»
client/   React + TypeScript + Vite
  src/lib/maqamat.ts   بيانات المقامات وأسماء النغمات العربية
  src/lib/audio.ts     محرك الصوت (وتر، صندوق، صدى، قرار مستمر)
  src/lib/pitch.ts     تتبّع طبقة الصوت وكشف المقام
  src/lib/wav.ts       تصدير WAV
  src/lib/lessons.ts   محتوى الدروس
  src/components/BrickLadder.tsx   سلّم الحجرات
```

المتغيرات: `PORT` (افتراضي 4300)، `MAQAM_DB` (مسار قاعدة البيانات)، `ADMIN_EMAILS`.

المُدوزِن يحتاج إذن الميكروفون، والمتصفحات لا تعطيه إلا على `localhost` أو `https`.
